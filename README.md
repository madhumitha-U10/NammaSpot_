# Namma Chennai Bazaar

Act as a senior full-stack ecommerce developer. Build NammaSpot, a mobile-first local marketplace connecting Chennai/Tamil Nadu customers with Instagram-based small businesses (bakers, mehendi artists, makeup/bridal, crochet, artists, boutiques, handmade creators, etc.).
DESIGN: Use my attached reference design as the base. Keep it clean, premium and minimal with a nostalgic Chennai/Tamil Nadu identity : warm cream/off-white, deep maroon, charcoal, subtle kolam/local-craft elements and authentic Chennai imagery. Avoid a generic ecommerce or tourism look. Fully responsive on mobile, tablet and laptop.
CUSTOMER: Home → Search → Explore → Categories → Near Me → Featured → Stories → Seller Profile → Catalogue → Enquiry/Booking.
SELLER: Register/Login → Dashboard → Overview → Business Profile → Catalogue → Enquiries → Customers → Instagram → Analytics → Settings.
ADMIN: Login → Seller Approval → Sellers → Products/Services → Categories → Enquiries → Reviews.
MVP TECH STACK (FREE): HTML + CSS + JavaScript frontend Google Apps Script backend/API Google Sheets database Google Drive for images Apps Script Web App hosting
DATABASE: Sellers, Products, Categories, Customers, Enquiries, Reviews.
CORE FLOW: Seller registers → creates profile → adds products/services → admin approves → public shareable seller profile. Customer searches → filters → views seller → views catalogue → sends enquiry/booking.
REQUIREMENTS:

Build production-quality responsive UI.

Mobile-first navigation.

Reusable components and clean folder structure.

Realistic Chennai/Tamil Nadu sample data.

Functional search, filters, seller profiles and enquiry forms.

Separate frontend/backend/database logic.

No paid services, unnecessary libraries or over-engineering.

Make it scalable for future Firebase/PostgreSQL migration.

Prioritize working functionality over excessive animations.
